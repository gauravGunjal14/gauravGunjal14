AI-powered coding platform inspired by LeetCode, built to practice DSA, solve coding problems, and get problem-focused AI assistance.

- Problem solving workspace with Monaco Editor
- Code execution and submissions

- AI-powered problem assistant

- Responsive and modern developer-first UI

- Fully deployed production application
